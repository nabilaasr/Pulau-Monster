## Deskripsi Game
Pulau Monster merupakan game 2D bergenre RPG yang mengajak pemain menjelajahi sebuah pulau, memilih monster partner, bertemu karakter NPC, menghadapi monster liar, dan bertarung melawan Boss.

Pemain dapat menjelajahi beberapa wilayah, yaitu Desa Awal, Hutan Lumut, dan Gua Petir.

## Fitur Utama
- Eksplorasi dunia 2D dengan sistem pergerakan empat arah.
- Pemilihan monster starter.
- Interaksi dan dialog dengan NPC.
- Sistem pertarungan monster berbasis giliran (*turn-based battle*).
- Monster liar dengan sistem AI.
- Sistem level, EXP, dan evolusi monster.
- Sistem penyimpanan progres permainan.
- Efek suara, musik latar, dan pencahayaan 2D.
- Pertarungan Boss dan ending permainan.

## Cara Membuka Proyek
1. Buka Unity Hub.
2. Pilih **Add** atau **Open**.
3. Pilih folder proyek `Pulau-Monster`.
4. Buka menggunakan Unity Editor versi 6000.3.24f1.
5. Tunggu hingga proses import aset dan kompilasi selesai.
6. Jalankan game melalui Unity Editor dengan menekan tombol Play.
